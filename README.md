# Brainita AI Tutor

Create a responsive educational web application called Brainita AI.

The website is for students from Class 4 to Class 12.

Create these pages:

 Login and signup

 Student onboarding

 AI Tutor page

 Profile page

On the AI Tutor page, keep a visual AI character on the left and a ChatGPT-style chat on the right. Both should stay on the same screen.

On mobile, place the visual character above the chat.

The onboarding page should ask:

 Name

 Class

 Board

 Goal

 Weak subjects

 Strong subjects

 Daily available study time

If the student is below Class 11, do not show NEET/JEE/WBJEE.

Use a modern, friendly educational design.
